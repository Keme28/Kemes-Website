# Ukemeobong Uduak Umo-Udofia (Keme) — Personal Portfolio & Living Automation Studio

Award-caliber personal portfolio and interactive resume for **Ukemeobong Uduak Umo-Udofia (Keme)**, Software Programmer & AI Automation Specialist based in Lagos, Nigeria.

## Core Concept: "RUN ME"
The portfolio operates as a self-executing automation workflow on a vast canvas:
- Machine precision x Human warmth.
- Deep Graphite (`#0C0C0D`), Ink (`#151517`), Bone (`#EFEAE0`), Signal (`#FF4F1F`), and Phosphor (`#B6FF5C`).
- Pinned horizontal scroll, self-drawing SVG wires, and traveling data pulses.
- Live interactive AI Automation Copilot with simulated RAG and MCP tool-calling.

## Project Structure
- `/src/content/site.ts`: **Single source of truth** for all copy, experience, projects, skills, and links.
- `/src/components/`:
  - `HeroSection.tsx`: Trigger Node 01, Instrument Serif colossal name, role line, portrait cutout with duotone hover effect.
  - `AboutSection.tsx`: Bone paper section scrub, sticky left column portrait & spec sheet, word-by-word scrub reveal, hand-drawn underlines.
  - `JourneySection.tsx`: Career path with self-drawing SVG wire, traveling Signal pulse, and unfolding experience nodes.
  - `WorkSection.tsx`: Desktop pinned horizontal scroll, card micro-strips (Input > Process > Output), metric counters, and live chatbot banner.
  - `AiChatbotModal.tsx`: Live AI Automation Copilot with simulated RAG vector lookup and MCP tool telemetry.
  - `ArchitectureDiagram.tsx`: Animated SVG topology with interactive nodes and live pulse simulation.
  - `CaseStudyModal.tsx`: Full-screen case study view with metrics, problem/solution, and architecture diagrams.
  - `CvModal.tsx`: Dual-mode curriculum vitae (Interactive Spec Sheet + Original PDF Viewer).
  - `GridBackground.tsx`: 2D Canvas interactive particle grid with cursor displacement ripple.
  - `CustomCursor.tsx`: Framer Motion spring-trailing cursor with morphing states.
  - `TopBar.tsx`: Fixed telemetry header with live Lagos time, monogram replay, and thin Signal scroll progress.
  - `IntroGate.tsx`: Terminal bootstrap sequence with Phosphor checkmarks and Flip expansion.
  - `DebugOverlay.tsx`: System internal inspector toggled with `D` key.
- `/public/`:
  - `keme-photo.jpg`: Tailored suit portrait of Ukeme.
  - `ukemeobong-umoudofia-cv.pdf`: Original verified 2-page curriculum vitae.

## How to Run Locally

### 1. Install dependencies
```bash
npm install
```

### 2. Start the local development server
```bash
npm run dev
```

### 3. Open in Browser
Visit `http://localhost:3000/` (or port assigned by Vite).
